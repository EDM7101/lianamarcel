# Optional: Keyhunt

[Keyhunt](https://github.com/albertobsd/keyhunt) und ähnliche Tools implementieren **Kangaroo**- oder andere strukturierte Verfahren. Sie passen **nicht** direkt zum Konzept dieses Scanners (rein zufällige Private Keys + VanitySearch-GPU-Pipeline).

Wer gezielt Key-Räume mit Pollard-Kangaroo bearbeiten will, sollte Keyhunt **separat** auf einer zweiten GPU/Instanz betreiben. Dieses Repository enthält keine Keyhunt-Binary oder -Patches.
